# cisco-packet-tracer-network-projectتصميم وإعداد شبكة باستخدام Cisco Packet Tracer

Network Design and Configuration Using Cisco Packet Tracer

الهدف من المشروع

إنشاء شبكة باستخدام برنامج Cisco Packet Tracer، وربط أجهزة الحاسب والراوتر وأجهزة الشبكة والخوادم، وإعداد خدمات الشبكة مثل DNS وHTTP والبريد الإلكتروني، بهدف تطبيق مفاهيم الشبكات عمليًا والتعرّف على آلية التواصل بين الأجهزة.

الأدوات والمكونات المستخدمة

* Cisco Packet Tracer
* أجهزة الحاسب (PCs)
* Router
* Switches
* Wireless Router
* Servers

المهام التي تم تنفيذها

* تصميم شبكة وربط أجهزة الحاسب ومكونات الشبكة.
* إعداد خدمة DNS وإضافة سجل للنطاق.
* تفعيل خدمتي HTTP وHTTPS على الخادم.
* إعداد خدمة البريد الإلكتروني.
* استقبال رسالة بريد إلكتروني على أحد أجهزة الحاسب.
* استخدام أمر Ping للتحقق من الاتصال بين الأجهزة.

نتيجة المشروع

تم إنشاء شبكة افتراضية باستخدام Cisco Packet Tracer، وإعداد عدد من خدمات الشبكة، مع نجاح استقبال رسالة بريد إلكتروني وظهور ردود ناجحة عند اختبار الاتصال باستخدام Ping.

المهارات المكتسبة

* تصميم الشبكات وربط مكوناتها.
* التعامل مع برنامج Cisco Packet Tracer.
* التعرف على إعدادات الراوتر والسويتش.
* إعداد خدمات DNS وHTTP وHTTPS.
* تطبيق خدمة البريد الإلكتروني.
* استخدام أمر Ping والتحقق من اتصال الأجهزة.
